# MyPotWorld 尘歌壶
- **作者**: 星梦
- **版本**: v0.5.0

## 功能概述
- 每个玩家一个**隔离的私人世界**（按 UUID 持久化，销毁后重进仍是自己的那个壶）
- 按需创建、闲置自动卸载（省内存），可停留在主世界随时返回
- **活动区域**：石板圈墙 + 反色漆，区域内可自由建造，**区域外禁止动土/倒液体**
- 越界立即传送回区域中心；圈墙被破坏会**立即修复**且不掉落
- **壶内开关**（按壶主独立）：禁止自然刷怪、无敌（离开壶自动清除）
- 可与其它假世界玩法**互通**（如 Boss 场地），并支持嵌套返回

## 指令
| 语法 | 说明 |
|------|------|
| /cg | 进入（或创建）自己的尘歌壶 |
| /cg exit | 离开并返回来源世界 |
| /cg status | 查看自己的壶状态 |
| /cg visit <玩家名> | 请求拜访他人的壶 |
| /cg join | 同意/进入他人的壶 |
| /cg contact | 进出壶时是否通知（个人开关） |
| /cg msg | 进出提示消息开关 |
| /cg sync | 客户端同步开关 |
| /cg area | 查看家园活动区域（尺寸/等级） |
| /cg area upgrade | 升级扩大活动区域（可配消耗） |
| /cg mob | 切换"壶内禁止自然刷怪" |
| /cg god | 切换"壶内无敌" |

## 配置
配置文件路径：`config/MyPotWorld/settings.json`
玩家个人状态：`config/MyPotWorld/players.json`

```json
{
  "启用": true,
  "最大同时存在数": 6,
  "闲置销毁_秒": 300,
  "互通_允许从假世界进入": true,
  "互通_允许的来源": [],
  "家园_活动区域_启用": true,
  "家园_活动区域_各级边长": [150, 200, 260, 330, 420],
  "家园_地面Y": 500,
  "家园_活动区域_圈墙图格ID": 273,
  "家园_活动区域_圈墙油漆ID": 30,
  "家园_活动区域_升级消耗物品ID": 0,
  "家园_活动区域_升级消耗基础数量": 0,
  "家园_活动区域_升级消耗每级递增": 0
}
```

## 配置说明
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|:------:|------|
| 启用 | 布尔值 | true | 是否启用尘歌壶 |
| 最大同时存在数 | 整数 | 6 | 同时存在的壶上限（内存保护，实测每壶约 220~260MB） |
| 闲置销毁_秒 | 整数 | 300 | 壶里没人多久后自动存档并卸载；**0 = 常驻不销毁** |
| 互通_允许从假世界进入 | 布尔值 | true | 是否允许从其它假世界直接进入 |
| 互通_允许的来源 | 数组 | [] | 允许的来源玩法标识白名单（如 ["BossArena"]），空 = 不限制 |
| 家园_活动区域_启用 | 布尔值 | true | 是否启用活动区域限制 |
| 家园_活动区域_各级边长 | 数组 | [150,200,260,330,420] | 每一级的区域边长（格），索引 = 等级；加载时强制非递减 |
| 家园_地面Y | 整数 | 500 | 家园地面的图格 Y（≈主世界地表），会按区域大小自动夹紧 |
| 家园_活动区域_圈墙图格ID | 整数 | 273 | 圈墙图格（273 = 石板） |
| 家园_活动区域_圈墙油漆ID | 整数 | 30 | 圈墙油漆（30 = 反色漆；-1 = 不刷漆） |
| 家园_活动区域_升级消耗物品ID | 整数 | 0 | 升级消耗的物品 ID（0 = 不消耗） |
| 家园_活动区域_升级消耗基础数量 | 整数 | 0 | 等级 0→1 的消耗数量 |
| 家园_活动区域_升级消耗每级递增 | 整数 | 0 | 每升一级额外增加的消耗 |

## 插件版本

- 壶内开关：禁止自然刷怪、无敌（按壶主独立，离开自动清除）
- 改名 MyPotWorld（显示名仍为「尘歌壶」）
- 使用 VirtualWorldCore（契约 v5）
