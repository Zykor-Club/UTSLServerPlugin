# MyPotWorld 尘歌壶
- **作者**: 星梦
- **版本**: v0.6.0

## 功能概述
- 每个玩家一个**隔离的私人世界**（按 UUID 持久化，销毁后重进仍是自己的那个壶）
- **进壶前选模板**：`/cg templates` 看可用建筑模板 → `/cg go <索引>` 建壶并贴入；活动区域按模板尺寸自适应
- 按需创建、闲置自动卸载（省内存），可停留在主世界随时返回
- **活动区域**：石板圈墙 + 反色漆，区域内可自由建造，**区域外禁止动土/倒液体**
- 越界自动回到区域内最近的空位；圈墙被破坏会**立即修复**且不掉落
- **壶内设置**（`/cg set`）：出生点、禁止刷怪、无敌、聊天互通、状态同步
- 可与其它假世界玩法**互通**（如 Boss 场地），并支持嵌套返回

## 指令（7 个顶层）
| 语法 | 说明 |
|------|------|
| `/cg` | 帮助（只列顶层指令，不列别名） |
| `/cg go [索引]` | 进入壶世界；首次必须先选模板 |
| `/cg exit` | 离开并返回来源世界 |
| `/cg info` | 壶状态 + 活动区域（控制台 / REST 亦可读） |
| `/cg info up` | 扩大活动区域一级（需在壶内，可配消耗） |
| `/cg tpl [页码]` | 建筑模板列表（[1] 棍母模板＝空模板，8 条/页） |
| `/cg tpl save <名字>` | 把当前活动区域存成模板（需在壶内） |
| `/cg visit <玩家名>` | 访问他人的壶（需 `tshock.admin`） |
| `/cg reset` | 重置本壶（连输两次确认；壶内先送回主世界） |
| `/cg set` | 设置项帮助（需在壶内） |
| `/cg set spawn` | 查看出生点 |
| `/cg set spawnset` | 把当前位置设为出生点 |
| `/cg set spawnclear` | 清除自定义出生点 |
| `/cg set mob` | 切换壶内禁止自然刷怪 |
| `/cg set god` | 切换壶内无敌 |
| `/cg set msg` | 切换聊天与主世界互通 |
| `/cg set sync` | 切换与主世界同步状态 |

> 旧名保留为别名：`/cg status`、`/cg area`、`/cg area upgrade`、`/cg templates`、`/cg save`。

## 进入流程
- `/cg tpl` 查看可用模板（[1] 棍母模板 = 空世界，无任何建筑；尺寸超过 **1500×1300** 的模板会标"不可选"）
- `/cg go <索引>` 选定模板 → 建壶 → 贴入模板 → 活动区域自适应 `边长 = max(等级尺寸, 模板最大边 + 10)`（如 160×160 → 170×170）→ 铺圈墙/出生点 → 放行
- **已有壶**：`/cg go` 直接进入；带索引也不会再生成模板（要换模板请 `/cg reset`）
- **旧版本壶**（没有模板记录）会被自动删除，要求重新选择模板（beta 阶段不做兼容）

```json

  "保存间隔_秒": 60,

  "互通_允许的来源": [],
  "家园_活动区域_启用": true,
```

## 配置说明
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|:------:|------|
| 启用 | 布尔值 | true | 是否启用尘歌壶 |
| 最大同时存在数 | 整数 | 6 | 同时存在的壶上限（内存保护，实测每壶约 220~260MB） |
| 闲置销毁_秒 | 整数 | 300 | 壶里没人多久后自动存档并卸载；**0 = 常驻不销毁** |
| 保存间隔_秒 | 整数 | 60 | 壶里有人时每隔多久落盘一次；0 = 关闭（进入/离开/贴模板/扩建本来就会存） |
| 互通_允许从假世界进入 | 布尔值 | true | 是否允许从其它假世界直接进入 |
| 互通_允许的来源 | 数组 | [] | 允许的来源玩法标识白名单（如 ["BossArena"]），空 = 不限制 |
| 家园_活动区域_启用 | 布尔值 | true | 是否启用活动区域限制 |
| 家园_活动区域_各级边长 | 数组 | [150,200,260,330,420] | 每一级的区域边长（格），索引 = 等级；加载时强制非递减 |
| 家园_地面Y | 整数 | 500 | 家园地面的图格 Y（≈主世界地表），会按区域大小自动夹紧 |
| 家园_活动区域_检查间隔毫秒 | 整数 | 300 | 圈墙完整性校验/修复的间隔（越界回传不受影响，仍每帧） |
| 家园_活动区域_圈墙图格ID | 整数 | 273 | 圈墙图格（273 = 石板） |
| 家园_活动区域_圈墙油漆ID | 整数 | 30 | 圈墙油漆（30 = 反色漆；-1 = 不刷漆） |
| 家园_活动区域_升级消耗物品ID | 整数 | 0 | 升级消耗的物品 ID（0 = 不消耗） |
| 家园_活动区域_升级消耗基础数量 | 整数 | 0 | 等级 0→1 的消耗数量 |
| 家园_活动区域_升级消耗每级递增 | 整数 | 0 | 每升一级额外增加的消耗 |

## 插件版本
### v0.6.2
- 玩家可见文案去掉条件/权限注解（如"（需在壶内）""（需 tshock.admin）"），帮助只保留命令与作用

### v0.6.1
- 指令合并（9 个顶层 → 7 个）：`status`+`area` → `/cg info`；`area upgrade` → `/cg info up`；`save` → `/cg tpl save`；`templates` → `/cg tpl`（旧名保留别名）
- 文案整改：去掉已失效的 `/cg paste`、`/cg 进入`、`/cg spawn` 提示；统一全角冒号；状态/模板页脚等描述精简
- 重置提示按对象区分：壶主看到"已重置，正在返回主世界"，访客看到"壶主重置了尘歌壶"
- 修复：玩家改名后按短键兜底找回壶存档（原先改名=丢壶）
- 修复：访问离线壶主时改用其账号 UUID 作为 key（原先用文件名短键，区域等级/模板对不上，且壶主上线会重复建实例）

### v0.6.0
- ★ 进壶流程重构：`/cg` 只显示帮助；`/cg go [索引]` 选模板后建壶；模板在放行前贴入；区域按模板自适应
- ★ `/cg templates [页码]`：8 条/页，[1] 恒为棍母模板（空模板），蓝→紫渐变色，标出"当前选择"与"不可选（超 1500×1300 / 文件损坏）"
- ★ 移除 `/cg paste`；`/cg save` 仍可在壶内把当前区域存成模板
- ★ 新增 `/cg reset`：连输两次确认，壶内会先把所有玩家送回原世界，再删世界/清模板/清区域等级/清出生点
- ★ 设置项合并：`/cg set spawn|spawnset|spawnclear|mob|god|msg|sync`（均需在壶内）；`/cg contact` 改名为 `/cg set msg`
- 旧版本（无模板记录）的壶自动删除，要求重新选择模板

### v0.5.1
- 越界回传：从活动区域中心向外自动找最近的"可站立空位"，找不到才回落中心半空；不再弹提示（只记日志）
- 新增 `/cg spawn` / `set` / `clear`：玩家自定义出生点（存相对区域中心的偏移，区域升级后不会跑到墙外）
- 修复："闲置销毁_秒 = 0（常驻）"时看护定时器不跑（Busy 卡死保护 / 定时存档 / 状态对账全部停摆）
- 性能：圈墙校验/修复按 `家园_活动区域_检查间隔毫秒` 节流（越界回传仍每帧）
- 控制台/REST 下 `/cg status` 有输出了（原来只对玩家输出，`/world/command` 永远拿到空）
- 建壶前校验"当前世界"与"主世界"尺寸，不一致时拒绝并提示（避免种子尺寸不符）

### v0.5.0
- 家园活动区域：石板+反色漆圈墙、区域外禁止动土/倒液体、越界回传中心
- 出生点位于活动区域竖直中部；地面高度可配（默认 500）
- 壶内开关：禁止自然刷怪、无敌（按壶主独立，离开自动清除）
- 改名 MyPotWorld（显示名仍为「尘歌壶」）
- 使用 VirtualWorldCore（契约 v5）
