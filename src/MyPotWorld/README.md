# MyPotWorld 尘歌壶
- **作者**: 星梦
- **版本**: v0.6.2

## 功能概述
- 每个玩家一个**隔离的私人世界**（按 UUID 持久化，销毁后重进仍是自己的那个壶）
- **进壶前选模板**：`/cg tpl` 看可用建筑模板 → `/cg go <序号>` 建壶并贴入；活动区域按模板尺寸自适应
- 按需创建、闲置自动卸载（省内存），可停留在主世界随时返回
- **活动区域**：石板圈墙 + 反色漆，区域内可自由建造，**区域外禁止动土/倒液体**
- 越界自动回到区域内最近的空位；圈墙被破坏会**立即修复**且不掉落
- **壶内设置**（`/cg set`）：出生点、禁止刷怪、无敌、聊天互通、状态同步
- 可与其它假世界玩法**互通**（如 Boss 场地），并支持嵌套返回

## 指令
| 语法 | 权限 | 说明 |
|------|:----:|------|
| `/cg` | - | 帮助（只列顶层指令，不列别名） |
| `/cg go [序号]` | - | 进入壶世界；首次必须先选模板 |
| `/cg exit` | - | 离开并返回来源世界 |
| `/cg info` | - | 壶状态 + 活动区域（控制台/REST 亦可读） |
| `/cg info up` | - | 扩大活动区域一级（需在壶内） |
| `/cg tpl [页码]` | - | 建筑模板列表（[1] 棍母模板＝空模板，8 条/页） |
| `/cg tpl save <名字>` | - | 把当前活动区域存成模板（需在壶内） |
| `/cg visit <玩家名>` | `tshock.admin` | 访问他人的壶 |
| `/cg reset` | - | 重置本壶（连输两次确认；壶内先送回主世界） |
| `/cg set` | - | 设置项帮助（需在壶内） |
| `/cg set spawn` | - | 查看出生点 |
| `/cg set spawnset` | - | 把当前位置设为出生点 |
| `/cg set spawnclear` | - | 清除自定义出生点 |
| `/cg set mob` | - | 切换壶内禁止自然刷怪 |
| `/cg set god` | - | 切换壶内无敌 |
| `/cg set msg` | - | 切换聊天与主世界互通 |
| `/cg set sync` | - | 切换与主世界同步状态 |

## 配置说明
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|:------:|------|
| 启用 | 布尔值 | true | 是否启用尘歌壶 |
| 最大同时存在数 | 整数 | 6 | 同时存在的壶上限（内存保护） |
| 闲置销毁_秒 | 整数 | 300 | 壶里没人多久后自动存档并卸载；0 = 常驻 |
| 保存间隔_秒 | 整数 | 60 | 壶里有人时每隔多久落盘；0 = 关闭 |
| 互通_允许从假世界进入 | 布尔值 | true | 是否允许从其它假世界直接进入 |
| 互通_允许的来源 | 数组 | [] | 来源玩法白名单，空 = 不限制 |
| 家园_活动区域_启用 | 布尔值 | true | 是否启用活动区域限制 |
| 家园_活动区域_各级边长 | 数组 | [150,200,260,330,420] | 每级区域边长（格），索引 = 等级 |
| 家园_地面Y | 整数 | 500 | 家园地面的图格 Y（会按区域大小自动夹紧） |
| 家园_活动区域_检查间隔毫秒 | 整数 | 300 | 圈墙校验/修复间隔（越界回传仍每帧） |
| 家园_活动区域_圈墙图格ID | 整数 | 273 | 圈墙图格（273 = 石板） |
| 家园_活动区域_圈墙油漆ID | 整数 | 30 | 圈墙油漆（30 = 反色漆；-1 = 不刷漆） |
| 家园_活动区域_升级消耗物品ID | 整数 | 0 | 升级消耗的物品 ID（0 = 不消耗） |
| 家园_活动区域_升级消耗基础数量 | 整数 | 0 | 等级 0→1 的消耗数量 |
| 家园_活动区域_升级消耗每级递增 | 整数 | 0 | 每升一级额外增加的消耗 |

## 说明
- **进入流程**：`/cg tpl` 查看模板 → `/cg go <序号>` 选定 → 建壶 → 贴入模板（水平+垂直居中）→ 区域自适应 `边长 = max(等级尺寸, 模板最大边 + 10)` → 铺圈墙/出生点 → 放行
- **已有壶**：`/cg go` 直接进入；带序号也不会再生成模板（要换模板请 `/cg reset`）
- **旧版本壶**（没有模板记录）会被自动删除，要求重新选择模板（beta 取舍）
- 模板尺寸超过 **1500×1300** 时标为"不可选"；选择会记在 `players.json`
- 世界状态（时间/天气/进度）由 `WorldChainSync` 同步，不属于本插件
