# AutoBroadcast 自动广播
- **作者**: Scavenger、Cai（UTSL 移植：星梦）
- **版本**: v1.1.4

## 功能概述
- 按秒计时自动广播，可指定颜色与用户组
- 支持聊天关键词触发（可选发给整组）
- 消息以 `/` 或 `.` 开头时按服务器指令执行

## 指令
| 语法 | 权限 | 说明 |
|------|:----:|------|
| `/ab list` | `autobroadcast.admin` | 查看广播列表 |
| `/ab reload` | `autobroadcast.admin` | 重载配置 |

## 配置
配置文件路径：`config/AutoBroadcast/settings.json`

```json
{
  "广播列表": [
    {
      "广播名称": "示例广播",
      "启用": false,
      "广播消息": ["/say Ciallo", "欢迎来到服务器"],
      "RGB颜色": [255, 234, 115],
      "时间间隔": 600,
      "延迟执行": 0,
      "广播组": [],
      "触发词语": [],
      "触发整个组": false
    }
  ]
}
```

## 配置说明
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|:------:|------|
| 广播名称 | 字符串 | 空 | 备注名 |
| 启用 | 布尔值 | false | 是否参与定时/触发 |
| 广播消息 | 数组 | [] | 每条；`/` 开头当作指令 |
| RGB颜色 | 数组 | [255,255,255] | 文本颜色 |
| 时间间隔 | 整数 | 0 | 秒；0 = 不定时 |
| 延迟执行 | 整数 | 0 | 首次延迟秒数 |
| 广播组 | 数组 | [] | 只发给这些组，空 = 所有人 |
| 触发词语 | 数组 | [] | 聊天包含即触发 |
| 触发整个组 | 布尔值 | false | 触发时发给整组 |

## 说明
- 定时器全局每秒一次，广播跨所有世界（UTSL 没有 `TSPlayer.All`，逐个发）
- 触发词来自 `ChatEvent`（客户端聊天文本）
- 触发逻辑照上游：若玩家**在该广播配置的组里**，则直接跳过（不再触发）
- `延迟执行` 每轮都生效（上游语义）
- 日志关键词：`[AutoBroadcast]`
