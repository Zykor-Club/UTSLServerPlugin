# DeathDrop 死亡掉落
- **作者**: 大豆子、肝帝熙恩（UTSL 移植：星梦）
- **版本**: v1.0.6

## 功能概述
- 怪物死亡时按概率额外掉落物品
- 两种模式：**全局随机**（全物品池随机 / 指定池随机）与**按怪物自定义**
- 可配置每种掉落的数量范围、概率、排除物品

## 指令
| 语法 | 权限 | 说明 |
|------|:----:|------|
| （无） | - | 本插件没有指令，全部由配置文件控制 |

## 配置
配置文件路径：`config/DeathDrop/settings.json`

```json
{
  "是否开启随机掉落": false,
  "完全随机掉落": false,
  "完全随机掉落排除物品ID": [],
  "普通随机掉落物": [757],
  "随机掉落概率": 100,
  "随机掉落数量最小值": 1,
  "随机掉落数量最大值": 1,
  "是否开启自定义掉落": false,
  "自定义掉落设置": [
    { "生物id": 4, "掉落概率": 50, "普通随机掉落物": [757] }
  ]
}
```

## 配置说明
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|:------:|------|
| 是否开启随机掉落 | 布尔值 | false | 全局随机掉落总开关 |
| 完全随机掉落 | 布尔值 | false | true = 从全部物品随机（可排除） |
| 完全随机掉落排除物品ID | 数组 | [] | 完全随机时排除的物品 |
| 普通随机掉落物 | 数组 | [] | 指定物品池 |
| 随机掉落概率 | 整数 | 100 | 0-100 |
| 随机掉落数量最小值/最大值 | 整数 | 1/1 | 包含边界 |
| 是否开启自定义掉落 | 布尔值 | false | 按怪物配置 |
| 自定义掉落设置 | 数组 | [] | 每项：生物id / 概率 / 物品池 / 数量范围 |

## 说明
- UTSL 没有 `Item.NewItem`，掉落改为**直接发给击杀者**（没有击杀者时给最近的玩家）
- 每个世界独立生成物品（按 `ServerContext` 取世界）
- 日志关键词：`[DeathDrop]`
