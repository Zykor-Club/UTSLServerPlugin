# EdgeStitch 多世界边缘无缝拼接
- **作者**: 星梦
- **版本**: v1.0.0

## 功能概述
- 把多个**同尺寸**世界沿边缘拼成一张连续的大地图
- 玩家走到世界边缘时自动进入相邻世界的对应边缘，落点与速度连续
- 利用 UTSL 单进程多世界的特性，换乘几乎无感（背包 / 血量 / buff 保留）
- 每 2 秒统一链上世界的时间 / 天气 / 入侵 / Boss 进度
- 相邻世界尺寸不一致时跳过该接缝并在日志中告警
- 默认控制台零输出，只有真故障才打日志

## 指令
本插件没有指令，所有行为由配置文件控制。

## 配置
配置文件路径：`config/EdgeStitch/EdgeStitch.json`

```json
{
  "世界链": ["West", "Dev", "East"],
  "首尾相连成环": false,
  "边缘带宽度_格": 64,
  "传送冷却_毫秒": 2500,
  "仅朝外移动时触发": true,
  "陆地边缘": {},
  "边缘触发余量_格": 24,
  "切片间距_格": 0,
  "不参与同步的世界": [],
  "启动日志": false,
  "换乘日志": false,
  "诊断日志": false,
  "诊断间隔_毫秒": 30000
}
```

## 配置说明
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|:------:|------|
| 世界链 | 数组 | ["West","Dev","East"] | 世界名顺序，必须与 config.json 的 autoStartServers.name 一致 |
| 首尾相连成环 | 布尔值 | false | 链的两端是否相连，可做成环 |
| 边缘带宽度_格 | 整数 | 64 | 没有配「陆地边缘」的世界：距边缘多少格内触发换乘 |
| 传送冷却_毫秒 | 整数 | 2500 | 同一玩家两次换乘的最小间隔，防止接缝处来回弹 |
| 仅朝外移动时触发 | 布尔值 | true | 只在玩家朝世界外侧移动时触发（建议保持开启） |
| 陆地边缘 | 对象 | {} | 各世界东西两侧「可通行陆地」的图格 X；键为世界名，值为 { "西": X, "东": X }，null 表示该侧没有接缝 |
| 边缘触发余量_格 | 整数 | 24 | 提前多少格触发，保证玩家不会踏进虚空 |
| 切片间距_格 | 整数 | 0 | >0 时启用「位置保持」落点：目标 X = 源 X ∓ 该值 |
| 不参与同步的世界 | 数组 | [] | 名单内世界不参与时间 / 天气 / 入侵 / Boss 进度的统一（大小写不敏感） |
| 启动日志 | 布尔值 | false | 插件加载时输出「世界链 / 运行中的世界 / 排除名单」自检行 |
| 换乘日志 | 布尔值 | false | 每次玩家换乘输出一条明细（源 / 目标 / 落点 / 地形） |
| 诊断日志 | 布尔值 | false | 玩家靠近边缘时周期性输出判定依据 + 同步汇总，排查用 |
| 诊断间隔_毫秒 | 整数 | 30000 | 诊断日志的最小输出间隔 |

## 换乘说明
> 客户端一次只能渲染一个世界，所以"无缝"的本质是：在玩家看到世界边界之前完成换乘，而不是真的把世界合并成一张图。因此相邻世界必须尺寸完全一致（UTSL 核心会直接拒绝尺寸不同的换乘）。

- 抹海缝合之后，世界两端是虚空而不是海洋，换乘边界不能再按"世界边缘"算，必须按各世界自己的陆地边缘算（见 `陆地边缘`）
- 换乘时会把源世界的时间 / 天气 / 入侵 / Boss 进度整体拷到目标世界；其余时间由每 2 秒的周期性统一完成
- NPC、掉落物、召唤物不会跟随换乘
- 日志关键词：`[EdgeStitch]`

## 世界状态同步
**同步参与方的判定规则**（按顺序）：

1. 只有出现在「世界链」里的世界才参与同步 —— 玩家随身世界、临时创建的空白世界天然不在链里，因此不会被同步，也不会污染原来的世界；
2. 链上但写在 `不参与同步的世界` 里的世界被排除；
3. 已停止（IsRunning=false）的世界也会被跳过。

开启「启动日志」后，插件启动时会打一行自检：

~~~
[EdgeStitch] 状态同步参与方: 链=[West / Dev / East]，当前运行的世界=3个[Dev, West, East]，排除名单=[]，诊断日志=关
~~~
