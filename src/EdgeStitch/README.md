# EdgeStitch 多世界边缘无缝拼接
- **作者**: 星梦
- **版本**: v1.2.1

## 功能概述
- 把多个**同尺寸**世界沿边缘拼成一张连续的大地图
- 玩家走到世界边缘时自动进入相邻世界的对应边缘，落点与速度连续
- 利用 UTSL 单进程多世界的特性，换乘几乎无感（背包 / 血量 / buff 保留）
- 相邻世界尺寸不一致时跳过该接缝并在日志中告警
- 世界状态同步已拆分到独立插件 `WorldChainSync`（同步类），本插件只负责换乘（拓展类）

## 指令
| 语法 | 权限 | 说明 |
|------|:----:|------|
| `/stitch` | - | 等同 `/stitch status` |
| `/stitch status` | - | 链、各世界尺寸/在线/陆地边缘、日志开关 |
| `/stitch reload` | `edgestitch.admin` | 重载配置并做运行期自检 |
| `/stitch on` | `edgestitch.admin` | 开启换乘（写回配置） |
| `/stitch off` | `edgestitch.admin` | 关闭换乘（写回配置） |
| `/stitch diag` | `edgestitch.admin` | 切换诊断日志（写回配置） |

## 配置
配置文件路径：`config/EdgeStitch/EdgeStitch.json`

```json
{
  "世界链": ["West", "Dev", "East"],
  "首尾相连成环": false,
  "边缘带宽度_格": 64,
  "传送冷却_毫秒": 2500,
  "仅朝外移动时触发": true,
  "陆地边缘": {},
  "边缘触发余量_格": 24,
  "切片间距_格": 0,
  "启用": true,
  "换乘日志": true,
  "诊断日志": false,
  "诊断间隔_毫秒": 5000
}
```

## 配置说明
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|:------:|------|
| 世界链 | 数组 | ["West","Dev","East"] | 世界名顺序，必须与 config.json 的 autoStartServers.name 一致 |
| 首尾相连成环 | 布尔值 | false | 链的两端是否相连，可做成环 |
| 边缘带宽度_格 | 整数 | 64 | 没有配「陆地边缘」的世界：距边缘多少格内触发换乘 |
| 传送冷却_毫秒 | 整数 | 2500 | 同一玩家两次换乘的最小间隔，防止接缝处来回弹 |
| 仅朝外移动时触发 | 布尔值 | true | 只在玩家朝世界外侧移动时触发 |
| 陆地边缘 | 对象 | {} | 各世界东西两侧「可通行陆地」的图格 X；null 表示该侧没有接缝 |
| 边缘触发余量_格 | 整数 | 24 | 提前多少格触发，保证玩家不会踏进虚空 |
| 切片间距_格 | 整数 | 0 | >0 时启用「位置保持」落点：目标 X = 源 X ∓ 该值 |
| 启用 | 布尔值 | true | 换乘总开关（`/stitch off` 会写回这里） |
| 换乘日志 | 布尔值 | true | 每次换乘输出一条明细 |
| 诊断日志 | 布尔值 | false | 玩家接近边缘时输出判定依据（排查用） |
| 诊断间隔_毫秒 | 整数 | 5000 | 诊断日志的最小输出间隔 |

## 说明
- 客户端一次只能渲染一个世界，所以"无缝"的本质是：在玩家看到世界边界之前完成换乘，而不是真的把世界合并成一张图；因此相邻世界必须尺寸完全一致
- 抹海缝合之后，世界两端是虚空而不是海洋，换乘边界按各世界自己的陆地边缘算（见 `陆地边缘`）
- 换乘时**不再**拷贝世界状态：时间/天气/进度由 `WorldChainSync` 负责
- NPC、掉落物、召唤物不会跟随换乘
- 日志关键词：`[EdgeStitch]`
- 启动只做静态自检（链数量/重复/数值/链外陆缘）；运行期检查用 `/stitch reload`
