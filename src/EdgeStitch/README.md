# EdgeStitch 多世界边缘无缝拼接
- **作者**: 星梦
- **版本**: v1.0.0
## 功能概述
- 把多个**同尺寸**世界沿边缘拼成一张连续的大地图
- 玩家走到世界边缘时自动进入相邻世界的对应边缘，落点与速度连续
- 利用 UTSL 单进程多世界的特性，换乘几乎无感（背包/血量/buff 保留）

> 客户端一次只能渲染一个世界，所以"无缝"的本质是：**在玩家看到世界边界之前完成换乘**，
> 而不是真的把世界合并成一张图。因此相邻世界必须**尺寸完全一致**
> （UTSL 核心会直接拒绝尺寸不同的换乘）。

## 配置
配置文件：`config/EdgeStitch/EdgeStitch.json`

| 配置项 | 默认 | 说明 |
|:--|:--|:--|
| `世界链` | West, Dev, East | 世界名顺序，必须与 `config/config.json` 的 `autoStartServers.name` 一致 |
| `首尾相连成环` | false | 链的两端是否相连，可做成环 |
| `边缘带宽度_格` | 24 | 距边缘多少格内触发换乘 |
| `传送冷却_毫秒` | 2500 | 同一玩家两次换乘的最小间隔，防止接缝处来回弹 |
| `仅朝外移动时触发` | true | 只在玩家朝世界外侧移动时触发（建议保持开启） |

## 说明
- 世界尺寸不同的相邻世界会被跳过并在日志中告警
- 时间/天气/boss进度是**每世界独立**的；NPC、掉落物、召唤物不会跟随换乘（召唤物保留可后续扩展）
- 日志关键词：`[EdgeStitch]`
