# WorldChainSync 世界链同步
- **作者**: 星梦
- **版本**: v1.3.0

## 功能概述
- 把「世界链」（同一张大地图切出来的多个世界）的**世界级状态**保持一致
- 两条同步路径：**换乘瞬时**（检测玩家所在世界变化，旧世界状态立刻拷到新世界）+ **周期统一**（每 2s 以有玩家的世界为权威）
- 同步内容按分组开关：时间 / 天气 / 血月 / 日食 / 南瓜月 / 霜月 / 史莱姆雨 / 渔夫任务 / 入侵 / 困难模式 / Boss进度 / 已解救NPC
- 玩家自身（buff/血量/背包/永久加成）不需要同步：UTSL 换乘迁移的是同一个 `Player` 对象

## 指令
| 语法 | 权限 | 说明 |
|------|:----:|------|
| - | - | 本插件没有指令，所有行为由配置文件控制 |

## 配置
配置文件路径：`config/WorldChainSync/WorldChainSync.json`

```json
{
  "世界链": ["West", "Dev", "East"],
  "检测间隔_毫秒": 250,
  "统一间隔_毫秒": 2000,
  "同步内容": {
    "时间": true,
    "天气": true,
    "血月": true,
    "日食": true,
    "南瓜月": true,
    "霜月": true,
    "史莱姆雨": true,
    "渔夫任务": true,
    "入侵": true,
    "困难模式": true,
    "Boss进度": true,
    "已解救NPC": true
  }
}
```

## 配置说明
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|:------:|------|
| 世界链 | 数组 | ["West","Dev","East"] | 参与同步的世界名（与 config.json 的 autoStartServers.name 一致） |
| 检测间隔_毫秒 | 整数 | 250 | 换乘检测间隔；越小越即时 |
| 统一间隔_毫秒 | 整数 | 2000 | 周期统一的间隔 |
| 同步内容 | 对象 | 全开 | 分组开关，见下 |
| 同步内容.时间 | 布尔值 | true | 时刻/昼夜/月相/月型/星星数/快进/日晷冷却/月晷冷却 |
| 同步内容.天气 | 布尔值 | true | 雨/雨时长/雨强/风力/云量/云背景 |
| 同步内容.血月 | 布尔值 | true | `bloodMoon` |
| 同步内容.日食 | 布尔值 | true | `eclipse` |
| 同步内容.南瓜月 | 布尔值 | true | `pumpkinMoon` |
| 同步内容.霜月 | 布尔值 | true | `snowMoon` |
| 同步内容.史莱姆雨 | 布尔值 | true | `slimeRain` / `slimeRainTime` |
| 同步内容.渔夫任务 | 布尔值 | true | `anglerQuest` / `anglerQuestFinished`（世界级委托） |
| 同步内容.入侵 | 布尔值 | true | 入侵类型/规模/起点/延迟 |
| 同步内容.困难模式 | 布尔值 | true | `hardMode` |
| 同步内容.Boss进度 | 布尔值 | true | 全部 `downed*` 旗标 |
| 同步内容.已解救NPC | 布尔值 | true | 8 个 `saved*` 旗标 |

## 说明
- 与 `EdgeStitch` 的分工：EdgeStitch 负责换乘（拓展），本插件负责状态一致（同步）；两者各读自己的配置，「世界链」建议保持一致
- 没人在线时跳过周期统一（世界不 tick、时间冻结，空写没意义）
- `Main.GameMode`（旅程/大师等）**不同步**：它属于世界属性，改写会让客户端显示异常
- 玩家自身属性不需要同步：渔夫任务完成次数（`anglerQuestsFinished`）、永久加成（`used*`）、血量/魔力/背包/buff 都随同一个 `Player` 对象迁移
- 沙尘暴相关字段在当前 OTAPI 的 `MainSystemContext` 里不存在，暂不支持
