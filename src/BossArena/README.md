# BossArena Boss 场地
- **作者**: 星梦
- **版本**: v0.1.0

## 功能概述
- 一个**公共**假世界 + 战斗平台，用于 Boss 战/试炼
- 同时是 `VirtualWorldCore` 抽象的**试金石**：新玩法接入时**核心零改动**才说明抽象够用
- 进入时自动铺战斗平台与石墙；可一键重置场地
- 支持与其它假世界（如尘歌壶）**互通**

## 指令
| 语法 | 权限 | 说明 |
|------|:----:|------|
| /ba | - | 进入 Boss 场地 |
| /ba exit | - | 离开并返回来源世界 |
| /ba reset | - | 重置场地 |
| /ba status | - | 查看场地状态 |

## 配置
配置文件路径：`config/BossArena/settings.json`

```json
{
  "互通_允许从假世界进入": true,
  "互通_允许的来源": [],
  "调试_否决进入": false
}
```

## 配置说明
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|:------:|------|
| 互通_允许从假世界进入 | 布尔值 | true | 是否允许从其它假世界直接过来 |
| 互通_允许的来源 | 数组 | [] | 允许的来源玩法标识白名单（如 ["MyPotWorld"]） |
| 调试_否决进入 | 布尔值 | false | 打开后一律否决进入（用于验证可否决事件真能拦住） |

## 说明
- 场地是**公共**假世界：所有玩家进的是同一个；离开时按返回栈原路返回
- 进入时自动铺战斗平台与石墙；`/ba reset` 清空并重铺
- 重置/卸载会先确认场地内没有 active 玩家，绝不踩掉有人的世界
- 世界状态（时间/天气）由 `WorldChainSync` 负责，不在本插件范围
