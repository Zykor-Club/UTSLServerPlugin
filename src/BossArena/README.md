# BossArena · Boss 场地

> 分类：UTSL 拓展类（`[assembly: RequiresCoreModule("VirtualWorldCore")]`）

## 它做什么

一个**公共**假世界 + 战斗平台的 Boss 场地。它同时是 `VirtualWorldCore` 抽象的**试金石**：
如果新玩法接入时**核心零改动**，就说明这个抽象没有漏掉东西。

- 独立世界、独立配置；
- 进入时铺战斗平台与石墙；
- `/ba reset` 重置场地。

## 命令

| 命令 | 作用 |
|:--|:--|
| `/ba` | 进入 Boss 场地 |
| `/ba exit` | 离开并返回来源世界 |
| `/ba reset` | 重置场地 |
| `/ba status` | 查看状态 |

## 配置要点

| 键 | 说明 |
|:--|:--|
| `互通_允许从假世界进入` | 是否允许从别的假世界（如尘歌壶）直接过来 |
| `互通_允许的来源` | 允许的来源玩法标识白名单（如 `["MyPotWorld"]`） |
| `调试_否决进入` | 打开后一律否决进入（用于验证可否决事件真的能拦住） |
