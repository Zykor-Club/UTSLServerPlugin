# AutoResetPlus 整链重置
- **作者**: Eustia & cc04 & Leader & 棱镜 & Cai & 肝帝熙恩 & 星梦
- **版本**: v1.0.0

## 功能概述
- 整链重置多世界：生成一张新源地图 → 重新切分 → 替换所有切片 → 重启服务器
- 多个世界由同一张大地图切分而来，各重置各的会让接缝立刻断裂，因此必须整链重置
- 分两阶段执行：阶段 1 在插件进程内准备并重启；阶段 2 在下一次启动时自动续跑
- 切分移出服务器进程（交给 UTSLStitchTool），峰值内存由 2x 降到 1x
- 内置几何自检：片宽 / 重叠量 / 源地图宽不是 200 的整数倍时自动修正到最近合法值并打 Warning

## 指令
| 语法 | 权限 | 说明 |
|------|:----:|------|
| /reset | reset.admin | 整链重置全部世界（/reset info 等价于 /rs info） |
| /resetdata | reset.admin | 重置数据（不换地图） |
| /rs info | reset.admin | 查看重置预设与状态 |
| /rs name <地图名> | reset.admin | 设置重置后世界名 |
| /rs seed <种子> | reset.admin | 设置下次重置种子 |
| /rsinfo | reset.admin | 查看重置状态（与 /rs info 等价） |

## 配置
配置文件路径：`config/AutoResetPlus/MultiWorld.json`

> ⚠️ **下面三个路径必须自己改**：源码内置的默认值是**作者本机路径**（`C:\Users\...`），
> 在别的机器上会因找不到文件而重置失败。本文示例用占位写法，**不要照抄**。

```json
{
  "源地图名": "SourceMap",
  "片宽": 4200,
  "源地图宽度": 12800,
  "源地图高度": 1500,
  "切片数": 3,
  "重叠量": 28,
  "世界链": ["West", "Dev", "East"],
  "切分工具路径": "<你自己的 UTSLStitchTool.exe 绝对路径>",
  "服务器路径": "<你自己的 UnifierTSL.exe 绝对路径>",
  "服务器工作目录": "<你自己的服务器工作目录>",
  "下次重置种子": null,
  "重置后世界名": null,
  "替换文件": {},
  "重置前指令": [],
  "重置后指令": [],
  "重置后SQL命令": [],
  "随机种子配置": {
    "开启": false,
    "最少数量": 2,
    "最多数量": 4,
    "种子列表": []
  }
}
```

## 配置说明
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|:------:|------|
| 源地图名 | 字符串 | SourceMap | 源大地图的世界名，会被临时加入启动列表用于生成 |
| 片宽 | 整数 | 4200 | 目标片宽，必须是 200 的整数倍（客户端区块宽 200） |
| 源地图宽度 | 整数 | 12800 | 由片宽 / 切片数 / 重叠量推导，一般不用手填 |
| 源地图高度 | 整数 | 1500 | 必须是 150 的整数倍（客户端区块高 150） |
| 切片数 | 整数 | 3 | 源地图切成几片（2~6 均验证过） |
| 重叠量 | 整数 | 28 | 相邻切片重叠格数，决定接缝连续性 |
| 世界链 | 数组 | ["West","Dev","East"] | 切片部署成的世界名，顺序即世界链顺序 |
| 切分工具路径 | 字符串 | 源码内置绝对路径 | UTSLStitchTool.exe 的路径 |
| 服务器路径 | 字符串 | 源码内置绝对路径 | 服务器可执行文件路径（用于重启） |
| 服务器工作目录 | 字符串 | 源码内置绝对路径 | 服务器工作目录 |
| 下次重置种子 | 字符串 | null | 空 = 随机 |
| 重置后世界名 | 字符串 | null | 空 = 沿用 |
| 替换文件 | 对象 | {} | 目标路径 -> ReplaceFiles 目录里的源文件名，空字符串表示删除该目标 |
| 重置前指令 | 数组 | [] | 重置前执行的指令（不含 /） |
| 重置后指令 | 数组 | [] | 重置后执行的指令（不含 /） |
| 重置后SQL命令 | 数组 | [] | 重置后执行的 SQL |
| 随机种子配置 | 对象 | 见下 | 重置完成后随机抽取若干条作为下次重置的种子 |
| 随机种子配置.开启 | 布尔值 | false | 是否启用随机种子池 |
| 随机种子配置.最少数量 | 整数 | 2 | 每次抽取的最少条数 |
| 随机种子配置.最多数量 | 整数 | 4 | 每次抽取的最多条数 |
| 随机种子配置.种子列表 | 数组 | [] | 可抽取的种子池 |

> 源码里还有一个 `ResetConfig`（`config/AutoResetPlus/AutoReset.<语言>.json`），当前代码没有引用它，实际生效的是上面的 `MultiWorld.json`。

## 工作流程
**阶段 1（插件进程内）**
- 广播倒计时 → 执行「重置前指令」→ 踢人
- 把 UTSL 启动列表切成「只留源地图」→ 写 pending-reset.json → 启动重启脚本 → 退出进程

**阶段 2（下次启动自动续跑）**
- 等源地图生成 → 主动触发保存 → 写 EdgeStitch 配置与启动列表
- 生成 PowerShell 脚本并退出（关键：切分移出服务器进程，峰值内存 2x → 1x）
- 脚本：切分 → 部署切片 → 执行「替换文件 / 重置后指令 / SQL / 抽下次种子」→ 启动服务器

## 几何自检（内置）
实测片宽或源地图宽不是 200 的整数倍会导致客户端小地图偏移、切分出错。插件会在重置前自动校验并修正到最近的合法值，同时打 Warning：

~~~
[AutoResetPlus] 片宽 4000 不是 200 的整数倍（会导致小地图偏移），已自动改为 4000...
[AutoResetPlus] 重叠量 28 会让源地图宽不是 200 的整数倍（区块残缺），已自动改为 100
~~~

## 各切片数对应参数（片宽 4200）
| 切片数 | 重叠量需为 | 建议 | 源地图宽 | 高度 | 图格 |
|:--|:--|:--|:--|:--|:--|
| 2 | 200 的倍数 | 200 | 7800 | 2400 | 1872万 |
| 3 | 100 的倍数 | 100 | 12000 | 2400 | 2880万 |
| 4 | 200 的倍数 | 200 | 15000 | 1800 | 2700万 |
| 5 | 50 的倍数 | 100 | 19800 | 1200 | 2376万 |
| 6 | 40 的倍数 | 120 | 23400 | 1200 | 2808万 |

## 依赖
- UTSL（UnifierTSL）
- EdgeStitch（读取 / 写入其配置以保持世界链一致）
- UTSLStitchTool（配套命令行切分工具）

## 说明
- 整链重置必须停服执行（阶段 1 在进程内准备并重启，阶段 2 下次启动自动续跑）；片宽/重叠量不合规时插件会自动修正并打 Warning。
